# ☁️ Cloudflare Worker 流量查询与后台管理系统

基于 **Cloudflare Workers + KV** 构建的轻量级流量查询与用户管理系统。

支持通过脚本自动同步用户流量数据，用户可以通过专属 Key 查询流量使用情况，管理员则可以通过 Web 后台统一查看所有用户的流量、账号状态及到期时间。

无需购买服务器，无需部署数据库，利用 Cloudflare 免费资源即可搭建自己的流量管理系统。

## ✨ 功能特点

### 👤 用户流量查询
- 支持通过专属 Key 查询用户流量。
- 实时展示已用流量、总流量及剩余流量。
- 自动计算流量使用百分比。
- 显示流量周期到期时间。
- 显示账号到期时间及剩余时间。
- 自动识别流量超限、账号到期等状态。
- 显示数据最后更新时间。

### 🔐 后台管理
- 独立管理员登录入口。
- 管理员密码验证。
- SVG 图形验证码，支持点击刷新。
- 用户列表统一管理。
- 支持查看所有用户的流量信息。
- 自动按照账号到期时间排序。
- 支持前端分页，每页显示 10 条。
- 点击用户即可弹出详细流量信息。
- 显示最后一次数据同步时间。

### 🔄 自动数据同步
- 提供 `/sync` API 接口。
- 支持通过 Bearer Token 进行身份验证。
- 支持批量同步用户数据。
- 自动清理已经不存在的用户。
- 自动记录数据同步时间。
- 使用 Cloudflare KV 保存用户数据。

### 🎨 页面设计
- 简洁现代的渐变 UI 风格。
- 自适应 PC 和移动端。
- 用户查询页面与管理后台独立。
- 支持 iframe 嵌入用户详情。
- 无需额外前端框架或第三方依赖。

## 📸 页面功能

| 页面 | 功能 |
|---|---|
| 用户查询页 | 输入 Key 查询流量 |
| 用户详情页 | 查看流量、账号到期时间及状态 |
| 管理员登录页 | 密码 + 图形验证码验证 |
| 用户管理后台 | 查看所有用户、分页及详情 |

## 🛠️ 部署教程

### 1. 创建 Cloudflare Worker

登录 [Cloudflare Dashboard](https://dash.cloudflare.com/)，进入：

`Workers 和 Pages` → `创建应用程序` → `创建 Worker`

创建完成后，将项目代码完整复制到 Worker 编辑器中并保存部署。

### 2. 创建 KV 命名空间

进入：

`Workers 和 Pages` → `KV` → `创建命名空间`

命名空间名称：

```text
SS_USERS
```

### 3. 绑定 KV

进入 Worker：

`设置` → `绑定` → `KV 命名空间`

添加绑定：

| 变量名称 | KV 命名空间 |
|---|---|
| SS_USERS | SS_USERS |

注意：变量名称必须填写 `SS_USERS`，需要与代码中的绑定名称保持一致。

### 4. 配置环境变量

进入 Worker：

`设置` → `变量和机密` → `添加`

添加以下三个变量：

| 变量名称 | 类型 | 说明 |
|---|---|---|
| SYNC_TOKEN | Secret | 数据同步接口鉴权 Token |
| ADMIN_PASSWORD | Secret | 后台管理员登录密码 |
| CAPTCHA_SECRET | Secret | 验证码签名密钥 |

建议使用足够复杂的随机字符串作为 Token 和密钥。

**注意：** 不要将真实密码、Token 或密钥直接写入公开代码仓库。

### 5. 完成部署

确认 KV 绑定和环境变量配置无误后，重新部署 Worker。

部署成功后即可使用。

## 🌐 访问地址

假设你的 Worker 域名为：

`https://your-worker.workers.dev`

| 地址 | 功能 |
|---|---|
| `/` | 用户流量查询首页 |
| `/?key=xxx` | 查询指定用户流量 |
| `/admin` | 后台管理登录入口 |
| `/captcha` | 获取图形验证码 |
| `/sync` | 用户数据同步接口（POST） |

## 🔄 数据同步接口

Worker 提供 `/sync` 接口，供外部脚本定时上传用户数据。

**请求方式：**

```http
POST /sync
Authorization: Bearer YOUR_SYNC_TOKEN
Content-Type: application/json
```

**请求示例：**

```json
{
  "users": [
    {
      "key": "user_key_001",
      "name": "用户001",
      "used": 5368709120,
      "limit": 107374182400,
      "expire": 1798761600,
      "traffic_expire": 1796083200,
      "status": "正常",
      "port": 10001
    }
  ]
}
```

**字段说明：**

| 字段 | 说明 |
|---|---|
| key | 用户唯一查询密钥 |
| name | 用户名称 |
| used | 已使用流量，单位 Byte |
| limit | 流量总额度，单位 Byte，0 表示不限 |
| expire | 账号到期时间，Unix 时间戳，0 表示永久 |
| traffic_expire | 流量周期到期时间，Unix 时间戳，0 表示不显示 |
| status | 用户状态 |
| port | 用户端口 |

**同步成功返回：**

```json
{
  "ok": true,
  "count": 1
}
```

注意：每次同步会根据本次提交的用户列表清理 KV 中已经不存在的用户数据，请确保上传的是完整用户列表，而不是增量数据。

## 📊 数据展示说明

流量使用情况：

- 自动换算 B、KB、MB、GB、TB。
- 根据流量使用比例显示进度条。
- 使用比例达到 70% 时显示警告颜色。
- 使用比例达到 90% 时显示危险颜色。

账号到期情况：

- 永久有效：显示永久。
- 剩余不足 7 天：显示即将到期。
- 已超过到期时间：显示已到期。

## 🔒 安全说明

- `/sync` 使用 Bearer Token 验证请求。
- 后台登录需要管理员密码和图形验证码。
- 验证码通过 HMAC-SHA256 签名验证。
- 验证码有效期为 5 分钟。
- 管理员登录 Cookie 有效期为 24 小时。
- 用户数据存储在 Cloudflare KV 中。

**安全建议：**
- 使用高强度随机密码。
- 定期更换同步 Token。
- 妥善保管环境变量。
- 建议进一步为后台增加登录失败限制及访问频率限制。

## 📌 注意事项

1. 本项目需要先完成 Cloudflare KV 绑定及环境变量配置。
2. 用户数据依赖外部脚本通过 `/sync` 接口上传。
3. 查询页面只能查询已经同步到 KV 的用户。
4. KV 缓存可能导致数据更新存在短暂延迟。
5. 当前管理后台采用前端分页，用户数据会在后台页面生成时加载。
